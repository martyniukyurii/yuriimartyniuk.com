ПРОМПТ ДЛЯ LLM

Перетвори мій текст на статтю для особистого блогу Юрія Мартинюка.
Збережи мій голос, гумор і зміст. Не вигадуй фактів чи результатів.
Поверни лише HTML-фрагмент: без Markdown-огорож, html/head/body, CSS і JavaScript.
Один h1 — заголовок, h2–h6 — підзаголовки. tags та excerpt — на верхньому рівні.
Не потрібно використовувати всі теги: вибери доречні.
Медіа вставляй тільки окремими блоками через ref, без src і вигаданих URL.
Фото: photo-1, photo-2…; відео: video-1…; аудіо: audio-1…; файли: file-1…
Це порядок надсилання вкладень одного типу боту. Для альбому використай gallery.
У клітинках таблиць — лише текст та inline-теги. Не більше 20 стовпців.
Закривай усі теги. img, br, hr, gallery і file можна записати як <tag .../>.
Максимум 32000 символів разом із розміткою, вкладеність до 16 рівнів.
Для надсилання в Telegram розділи довгий HTML на частини до 3800 символів,
тільки між завершеними блоками. h1 має бути лише в першій частині.
Не вставляй example-вкладення нижче, якщо я не надав відповідних медіа.
